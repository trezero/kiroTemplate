# Project Status Pattern

## Status Structure
```
# Project Status - [Date]

## Active Features
- [Feature]: [Status] - [Next Action]

## Completed This Session
- [Achievement 1]
- [Achievement 2]

## Next Session Priority
1. [Priority 1]
2. [Priority 2]

## Context Preservation
- Key decisions made
- Patterns established
- Workflows created
```

## Update Triggers
- Feature completion
- Session end
- Major decisions
- Workflow changes

## Location
`.kiro/status.md` - Always current project state
