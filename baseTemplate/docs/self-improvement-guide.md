# Self-Improvement Process Guide

## Session Analysis Framework

### 1. Agent Architecture Review
- **Character limits**: Identify agents over 2,500 chars (warning) or 3,000 chars (critical)
- **Capability gaps**: Find missing specialized agents for common tasks
- **Resource optimization**: Move detailed content from prompts to docs/
- **Duplication detection**: Identify overlapping agent responsibilities

### 2. Structure Validation
- **Directory compliance**: Ensure .kiro/ follows best practices
- **Content organization**: Validate files are in correct directories
- **Resource references**: Check agent resources point to existing files
- **Format consistency**: Ensure JSON agents, markdown docs, proper naming

### 3. Performance Optimization
- **Agent loading speed**: Keep prompts focused and concise
- **Resource efficiency**: Use hybrid architecture (focused agents + detailed docs)
- **Context management**: Prevent agent prompt bloat
- **Tool permissions**: Ensure minimal necessary permissions only

### 4. Continuous Improvement Actions
- **Immediate fixes**: Character limit violations, broken resources
- **Structural improvements**: Directory reorganization, content migration
- **New capabilities**: Missing agents, patterns, prompts
- **Documentation updates**: Keep guides current with changes

## Implementation Workflow

1. **Analyze session learnings** - What patterns emerged?
2. **Identify specific improvements** - Concrete, actionable changes
3. **Prioritize by impact** - High-impact, low-effort first
4. **Log to improvements.md** - Track planned changes
5. **Implement immediately** - Don't defer valuable improvements
6. **Validate results** - Ensure changes work as expected
7. **Clean up logs** - Remove completed improvements

## Success Metrics

- All agents under 3,000 characters
- No broken resource references
- Clear separation of concerns between agents
- Comprehensive coverage of Recipe Raiders workflows
- Fast agent loading and execution
- Maintainable, scalable architecture
