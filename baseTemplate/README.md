# Universal Base Template - Streamlined Kiro CLI Setup

This is the streamlined universal base template that provides essential agents beneficial for any coding project, regardless of technology stack.

## 🎯 Philosophy

This base template includes only the most universally beneficial agents that work across any programming language, framework, or project type. Project-specific agents can be added later using the `template-manager` agent.

## 🤖 Included Agents (13 Universal Agents)

### Core Analysis & Improvement
- **`project-detector`** - Analyzes any project to determine technology stack and requirements
- **`code-analysis`** - Universal code quality analysis across any programming language
- **`code-refactor`** - Language-agnostic code refactoring and maintainability improvements
- **`self-improve`** - Continuous optimization of the Kiro CLI setup

### Development Workflow
- **`development-workflow`** - Build automation, CI/CD, and process optimization
- **`dependency-management`** - Package updates, security, and dependency optimization
- **`environment-setup`** - Development environment configuration and MCP server setup

### Project Management
- **`project-status`** - Project documentation and status reporting
- **`docs-navigator`** - Documentation management and navigation
- **`cli-error-recovery`** - Universal CLI error analysis and recovery
- **`template-manager`** - Template customization and agent management

### Setup & Testing
- **`kiro-setup`** - Intelligent project initialization and configuration
- **`automated-browser-testing`** - Web application testing with screenshot evidence

## 🚀 Quick Start

```bash
# 1. Navigate to your project directory
cd /path/to/your/project

# 2. Install base template
/path/to/kiroTemplate/baseTemplate/install-kiro-template.sh

# 3. Analyze your project and get customization recommendations
kiro-cli --agent project-detector

# 4. Customize template for your specific needs
kiro-cli --agent template-manager

# 5. Start developing with universal agents
kiro-cli
```

## 🎨 Customization Workflow

1. **Start with base template** - Universal agents that work everywhere
2. **Run project-detector** - Analyzes your specific project needs
3. **Use template-manager** - Adds project-specific agents and configurations
4. **Iterate and improve** - Use self-improve agent for continuous optimization

## 📋 Agent Descriptions

### `project-detector`
Analyzes your project structure, dependencies, and configuration files to determine the technology stack and recommend appropriate customizations.

### `code-analysis` 
Performs universal code quality analysis including structure review, performance optimization opportunities, security best practices, and maintainability improvements.

### `code-refactor`
Helps refactor code across any language by identifying code smells, extracting reusable components, eliminating duplication, and improving overall structure.

### `development-workflow`
Optimizes development processes including build automation, CI/CD pipelines, Git workflows, and deployment processes.

### `dependency-management`
Manages package dependencies, security vulnerabilities, version conflicts, and optimization across any package manager ecosystem.

### `environment-setup`
Configures development environments, MCP servers, tool installations, and environment variables for any project type.

### `template-manager`
Helps customize the base template by adding project-specific agents, configuring specialized tools, and optimizing the setup for your needs.
