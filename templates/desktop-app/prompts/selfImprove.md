# Self-Improvement Session End Protocol

Execute the session end protocol from `.kiro/workflows/self-improve.md`:

## Instructions
1. **Analyze session patterns and outcomes**
   - Review what was accomplished in this session
   - Identify any recurring patterns or issues encountered
   - Note any blockers or challenges faced

2. **Identify efficiency improvements**
   - Look for duplicated code or logic
   - Identify opportunities for reusable components
   - Note any manual processes that could be automated
   - Consider tooling or workflow enhancements

3. **Log to improvements.md**
   - Document specific improvement suggestions
   - Include rationale and expected benefits
   - Prioritize by impact and effort

4. **Evaluate against existing tools**
   - Check if improvements align with existing patterns
   - Consider compatibility with current architecture
   - Assess if new tools/agents would be beneficial

5. **Recommend next steps**
   - Suggest immediate actionable improvements
   - Identify longer-term enhancements
   - Propose any new agents or workflows needed

## Output Format
Provide a structured summary with:
- **Session Summary**: What was accomplished
- **Patterns Observed**: Recurring themes or issues
- **Efficiency Improvements**: Specific suggestions with priority
- **Recommended Actions**: Next steps to take
