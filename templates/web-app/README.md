# web-app Template

This is a specialized Kiro CLI template for web-app projects.

## Installation

From your project root:
```bash
git clone https://github.com/trezero/kiroTemplate.git temp
cd temp
./templates/web-app/install-kiro-template.sh
cd ..
rm -rf temp
```

## Customizations

This template includes:
- **Component management** - React/Vue/Angular component CRUD operations
- **User workflow optimization** - Authentication, routing, state management
- **API integration** - REST/GraphQL client setup and data fetching
- **Deployment automation** - Vercel, Netlify, AWS deployment pipelines
- **MCP Servers** - Vercel Agent-Browser, Context7, Deployment tools

## Specialized Agents

- `component-management` - Create, modify, and organize UI components
- `user-workflow` - Handle authentication, navigation, and user flows
- `api-integration` - Manage API calls, data fetching, and state
- `deployment` - Automate build and deployment processes
- `ui-testing` - Component testing and visual regression testing

## Technology Support

- **Frontend:** React, Vue, Angular, Svelte, Next.js, Nuxt.js
- **Styling:** Tailwind CSS, Styled Components, CSS Modules, SCSS
- **State:** Redux, Zustand, Pinia, Context API
- **Testing:** Jest, Vitest, Cypress, Playwright
- **Build:** Vite, Webpack, Parcel, Rollup
