# Session Initialization Protocol

## Standard Project Analysis Sequence
1. **Authentication Status Check**
   - Verify Firebase configuration
   - Check Google OAuth setup
   - Validate API keys and services

2. **Database Schema Validation**
   - Check migration status
   - Verify table structures
   - Test data integrity

3. **Dependency Audit**
   - Scan for unused packages
   - Check for platform-specific code
   - Validate environment configurations

4. **Integration Status**
   - Test external API connections
   - Verify OAuth flows
   - Check calendar/service integrations

5. **Documentation Update**
   - Generate current project status
   - Update architecture notes
   - Log any issues found

Use this protocol at session start for comprehensive project understanding.
