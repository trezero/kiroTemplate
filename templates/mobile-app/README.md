# Mobile App Template

This is a specialized Kiro CLI template for mobile app projects.

## Installation

From your project root:
```bash
git clone https://github.com/trezero/kiroTemplate.git temp
cd temp
./templates/mobile-app/install-kiro-template.sh
cd ..
rm -rf temp
```

## Customizations

This template includes:
- **Screen management** - Mobile UI components and navigation
- **Navigation workflow** - Stack, tab, and drawer navigation patterns
- **Native integration** - Device APIs, permissions, platform features
- **Mobile UI optimization** - Responsive design, touch interactions
- **MCP Servers** - Context7, Vercel Agent-Browser, Mobile testing tools

## Specialized Agents

- `screen-management` - Create and organize mobile screens and components
- `navigation-workflow` - Handle navigation patterns and routing
- `native-integration` - Access device features and native APIs
- `mobile-ui` - Optimize UI for mobile platforms and interactions
- `mobile-testing` - Device testing, emulation, and performance

## Technology Support

- **Frameworks:** React Native, Flutter, Ionic, Xamarin
- **Navigation:** React Navigation, Flutter Navigator, Ionic Router
- **State:** Redux, MobX, Provider, Riverpod
- **Native:** Expo, React Native CLI, Flutter SDK
- **Testing:** Detox, Appium, Flutter Driver, Maestro
