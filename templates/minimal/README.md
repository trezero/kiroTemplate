# minimal Template

This is a specialized Kiro CLI template for minimal projects.

## Installation

From your project root:
```bash
git clone https://github.com/trezero/kiroTemplate.git temp
cd temp
./templates/minimal/install-kiro-template.sh
cd ..
rm -rf temp
```
